# Carvolume — пульт динамиков в машине

Сайт для телефона, с которого можно управлять каждым динамиком в машине:
например, оставить звук только в передних, а задние выключить.

**Что умеет:**

- схема машины: нажали на динамик — он включился или выключился;
- быстрые режимы: «Все динамики», «Только передние», «Только задние», «Только водитель», «Тише сзади»;
- общая громкость и кнопка «без звука»;
- баланс (лево/право) и фейдер (перед/зад) на одной панели: тянете точку пальцем;
- свой уровень для каждого динамика, включая сабвуфер;
- можно управлять с нескольких телефонов сразу, изменения видны всем мгновенно;
- настройки сохраняются и восстанавливаются после перезапуска;
- можно установить на телефон как приложение (PWA), есть светлая и тёмная тема;
- необязательный PIN-код, чтобы пассажиры не баловались.

## Как это работает

Браузер на телефоне сам не может переключать динамики в машине. Нужно небольшое
устройство в машине, которое реально меняет громкость каналов. Сайт — это пульт для него:

```
Телефон (сайт)  ──Wi-Fi──▶  Сервер Carvolume  ──▶  Драйвер  ──▶  Усилитель / динамики
                             (Raspberry Pi и т.п.)
```

Если открыть сайт без сервера (просто файл или статический хостинг), он работает
в **демо-режиме**: всё можно покрутить, но звук в машине не меняется.

## Быстрый старт

Нужен Node.js 18 или новее. Сторонние пакеты не нужны.

```bash
npm start
```

Откройте `http://localhost:8080`. Сервер выведет в консоль адрес, который надо открыть
с телефона в той же Wi-Fi-сети (например, `http://192.168.4.1:8080`).

Без `config.json` сервер работает с драйвером `mock`: громкости просто пишутся в консоль.

## Подключение к реальным динамикам

Скопируйте `config.example.json` в `config.json` и выберите драйвер.

### Вариант 1. Raspberry Pi + многоканальная звуковая карта (`pactl`)

Самый простой путь сделать всё своими руками:

1. Raspberry Pi (или любой мини-ПК с Linux) + USB-звуковая карта на 4 канала (4.0 или 5.1).
2. Выходы карты подключены к 4-канальному автомобильному усилителю, а он — к динамикам.
3. Музыка идёт на Pi (Bluetooth-приёмник, Spotify Connect, AirPlay и т.п.) через PipeWire/PulseAudio.
4. Pi раздаёт Wi-Fi или подключается к точке доступа телефона.

```json
{
  "driver": "pactl",
  "driverOptions": {
    "sink": "@DEFAULT_SINK@",
    "channelOrder": ["fl", "fr", "rl", "rr"]
  }
}
```

`channelOrder` — порядок каналов звукового выхода. Его можно посмотреть командой
`pactl list sinks` в строке «Channel Map». Для 5.1 (`front-left,front-right,rear-left,rear-right,front-center,lfe`)
укажите `["fl", "fr", "rl", "rr", 0, "sub"]`: число вместо названия — фиксированная громкость
канала (здесь центральный канал выключен).

Чтобы стереозвук шёл во все 4 канала, включите в PipeWire/PulseAudio апмикс
(`enable-remixing = yes` / `channelmix.upmix = true`).

### Вариант 2. Свой скрипт (`command`)

Для любого оборудования, которым можно управлять из командной строки: DSP-процессор, реле
на GPIO, `amixer` и т.д.

```json
{
  "driver": "command",
  "driverOptions": { "command": "/home/pi/set-speakers.sh" }
}
```

Скрипт получает громкость каждого динамика в процентах (0–100) сразу тремя способами:

- аргументами: `fl=50 fr=50 rl=0 rr=0 sub=50`;
- переменными окружения: `SPK_FL`, `SPK_FR`, `SPK_RL`, `SPK_RR`, `SPK_SUB`;
- JSON в stdin: `{"gains": {...}, "state": {...}}`.

Пример: реле, которые отключают задние динамики на Raspberry Pi:

```sh
#!/bin/sh
[ "$SPK_RL" -gt 0 ] && pinctrl set 17 dh || pinctrl set 17 dl
[ "$SPK_RR" -gt 0 ] && pinctrl set 27 dh || pinctrl set 27 dl
```

### Вариант 3. Микроконтроллер по Wi-Fi (`http`)

Сервер отправляет `POST` с JSON `{"gains": {"fl":50,"fr":50,"rl":0,"rr":0,"sub":50}, "state": {...}}`
на указанный адрес, например на ESP32 с цифровым аудиопроцессором (PT2314, TDA7419) или реле.

```json
{
  "driver": "http",
  "driverOptions": { "url": "http://192.168.4.50/speakers" }
}
```

## Настройки

| Параметр        | Переменная окружения | По умолчанию | Описание                                   |
|-----------------|----------------------|--------------|--------------------------------------------|
| `port`          | `PORT`               | `8080`       | порт сайта                                 |
| `host`          | `HOST`               | `0.0.0.0`    | адрес, на котором слушать                  |
| `pin`           | `PIN`                | пусто        | PIN-код для доступа к пульту               |
| `driver`        | `DRIVER`             | `mock`       | `mock`, `pactl`, `command`, `http`         |
| `driverOptions` | —                    | `{}`         | настройки драйвера (см. выше)              |

Путь к файлу настроек можно задать переменной `CONFIG`.

## API

Для своих интеграций (например, кнопка на руле через Home Assistant):

| Запрос                         | Что делает                                       |
|--------------------------------|--------------------------------------------------|
| `GET /api/info`                | список динамиков и пресетов, нужен ли PIN        |
| `GET /api/state`               | текущее состояние и итоговые громкости           |
| `PATCH /api/state`             | изменить часть состояния                         |
| `POST /api/presets/{id}`       | включить пресет (`all`, `front`, `rear`, `driver`, `quiet-rear`) |
| `GET /api/events`              | поток обновлений (Server-Sent Events)            |

Если задан PIN, передавайте его в заголовке `X-PIN` или параметре `?pin=`.

Пример: выключить задние динамики:

```bash
curl -X PATCH http://192.168.4.1:8080/api/state \
  -H 'content-type: application/json' \
  -d '{"speakers": {"rl": {"on": false}, "rr": {"on": false}}}'
```

Формат состояния:

```json
{
  "master": 50,
  "muted": false,
  "balance": 0,
  "fader": 0,
  "speakers": {
    "fl":  { "on": true,  "level": 100 },
    "fr":  { "on": true,  "level": 100 },
    "rl":  { "on": false, "level": 100 },
    "rr":  { "on": false, "level": 100 },
    "sub": { "on": true,  "level": 100 }
  }
}
```

`balance`: от −100 (только левые) до +100 (только правые); `fader`: от −100 (только задние)
до +100 (только передние). Итоговая громкость динамика = общая × уровень динамика × баланс × фейдер.

## Автозапуск на Raspberry Pi

`/etc/systemd/system/carvolume.service`:

```ini
[Unit]
Description=Carvolume
After=network.target sound.target

[Service]
User=pi
WorkingDirectory=/home/pi/Carvolume
ExecStart=/usr/bin/node server/index.js
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now carvolume
```

> Для драйвера `pactl` сервис должен работать от того же пользователя, что и PipeWire/PulseAudio,
> иначе понадобится `Environment=XDG_RUNTIME_DIR=/run/user/1000`.

## Разработка

```bash
npm test
```

Структура:

- `public/` — сайт (HTML, CSS, JS без сборки);
- `public/js/mixer.js` — расчёт громкостей, общий для сайта и сервера;
- `server/app.js` — HTTP-сервер и API;
- `server/drivers.js` — драйверы оборудования;
- `test/` — тесты.
